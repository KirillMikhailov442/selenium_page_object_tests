# Selenium Page Object Tests

Финальный проект курса Stepik «Автоматизация тестирования с помощью Selenium и Python».
Тесты учебного интернет-магазина используют Selenium, pytest и Page Object Model.

## Установка

Нужны Python 3.10+ и установленный Google Chrome. Selenium Manager автоматически
подбирает драйвер; при первом запуске требуется доступ в интернет.

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

В Windows окружение активируется командой `.venv\Scripts\activate`.

## Проверка финального задания

```sh
pytest -v --tb=line --language=en -m need_review
```

Будут выбраны ровно четыре сценария:

- добавление товара гостем;
- пустая корзина при переходе со страницы товара;
- переход со страницы товара на страницу логина;
- добавление товара зарегистрированным пользователем.

`TestUserAddToBasketFromProductPage.setup` регистрирует нового пользователя с уникальным
email перед тестом. Учётные данные относятся только к учебному магазину; личные пароли не нужны.
Каждый тест получает отдельный браузер, который закрывается после выполнения.

## Остальные проверки

```sh
pytest -v --language=en
pytest -v --language=en -m promo
pytest -v --language=en -m need_review --headless
```

Для Firefox: `--browser_name=firefox` (требуется установленный Firefox).
Проверки текста пустой корзины рассчитаны на `--language=en`.

Промоакция `offer7` содержит известный баг: сообщение меняет название товара.
Этот параметр и две намеренно падающие отрицательные проверки отмечены `xfail(strict=True)`.
Все локаторы находятся в `pages/locators.py`, действия и утверждения — в классах страниц.
В тестах нет селекторов и `assert`; название и цена товара считываются перед добавлением.
